# 📝 To-Do List App

A clean, interactive, and responsive To-Do List application built from scratch using pure front-end web technologies. 

## 🚀 Features
- **Add Tasks:** Create tasks by typing into the input field and submitting via button or `Enter` key.
- **Toggle Status:** Mark tasks as completed or active using check boxes.
- **Delete Tasks:** Remove individual task items instantly.
- **Filter Tasks:** Filter the task list dynamically by *All*, *Active*, or *Completed*.
- **Data Persistence:** Tasks persist across browser refreshes and reopens using `localStorage`.
- **Responsive Layout:** Clean design built with CSS Flexbox that works across mobile, tablet, and desktop screens.

## 🛠️ Technologies Used
- **HTML5:** Semantic structural layout (`<header>`, `<form>`, `<ul>`, `<input>`).
- **CSS3:** Flexbox layout, custom variables, hover states, transitions, and clean modern typography.
- **JavaScript (ES6+):** Event listening, dynamic DOM generation, state array management, and `localStorage` synchronization.
